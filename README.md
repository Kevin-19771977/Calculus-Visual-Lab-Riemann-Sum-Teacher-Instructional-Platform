# 微積分視覺實驗室｜黎曼和教學平台

這是 Streamlit 版的黎曼和互動視覺化教學平台。

## 內容
- `app.py`：主程式
- `requirements.txt`：所需套件

## 本機執行方式
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 功能
- 左端點法、右端點法、中點法、隨機取點法
- 四種方法比較
- 友善函數輸入（例如 `x^2`、`2x`、`3(x+1)`、`|x|`、`ln(x)`、`log10(x)`、`log2(x)`）
- 側邊欄輸入語法說明
- 區間左右並排輸入
